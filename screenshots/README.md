## Capture Guidelines for High Quality Presentation

1. **Resolution:** Capture at minimum 1920x1080 resolution.
2. **Editor Appearance:** Use a dark theme (VS Code Dark+, One Dark Pro, or DBeaver Dark) with 16px font size.
3. **Cropping:** Crop out personal window title bars, taskbars, and unrelated browser tabs.
4. **Format:** Save image files in PNG format inside this `screenshots/` directory.
